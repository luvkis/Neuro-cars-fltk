# NeuroCars: Нейроэволюция на C++ 🚗🧠

Симуляция, в которой машинки учатся проходить трассу с нуля с помощью алгоритмов нейроэволюции (генетический алгоритм + нейронные сети). Проект написан на C++ с использованием кроссплатформенной графической библиотеки FLTK.

## Особенности проекта
* **Интерактивность:** Пользователь сам рисует границы трассы перед стартом симуляции.
* **Наглядность:** Процесс обучения происходит в реальном времени. Можно наблюдать, как машинки первых поколений врезаются в первую же стену, а последующие — адаптируются и проходят трек всё дальше.
* **Модульная архитектура:** Проект четко разделен на физический движок (кинематика, коллизии, сенсоры), ядро ИИ и графический интерфейс.

## Требования для сборки
* C++17 (или выше)
* CMake (версия 3.10+)
* Библиотека FLTK

## Инструкция по сборке и запуску

### Для macOS
1. Установите необходимые инструменты (если не установлены):
   `brew install cmake fltk`
2. Склонируйте репозиторий:
   `git clone https://github.com/ВАШ_ЛОГИН/neuro-cars-fltk.git`
3. Перейдите в папку проекта:
   `cd neuro-cars-fltk`
4. Сгенерируйте файлы сборки:
   `cmake -B build`
5. Соберите проект:
   `cmake --build build`
6. Запустите исполняемый файл:
   `./build/NeuroCars`

### Для Windows
1. Убедитесь, что у вас установлен CMake и компилятор (например, MinGW или MSVC через Visual Studio).
2. Скачайте и соберите FLTK (рекомендуется использовать пакетный менеджер `vcpkg` или собрать библиотеку из исходников).
3. Склонируйте репозиторий:
   `git clone https://github.com/ВАШ_ЛОГИН/neuro-cars-fltk.git`
4. Перейдите в папку проекта и сгенерируйте файлы:
   `cmake -B build`
5. Соберите проект:
   `cmake --build build --config Release`
6. Запустите `NeuroCars.exe` из папки `build/Release`.
